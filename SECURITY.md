# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest (`main`) | Yes |

## Reporting a Vulnerability

If you find a security problem in fidget-watching, please report it privately:

1. **Don't open a public GitHub issue.**
2. Email **nate@lorecraft.io**, or use GitHub's private reporting: the repo's **Security** tab → **Report a vulnerability**, also at <https://github.com/fidgetcoding/fidget-watching/security/advisories/new>. Either way, only the maintainer sees it.
3. Include what you found, how to reproduce it, and what it could affect.
4. You'll hear back within 48 hours.

## What's worth reporting

Anything where a URL, a video or its captions could make it run a command it shouldn't, write files where it shouldn't, or expose an API key or the browser cookies you let it use.
